# Presentation Diagrams

The 18 SVG diagrams used by (or alongside) the deck.

**These are copies.** The canonical set, with the full index, the palette and the
readability notes, is in [`../../Assets/Diagrams/`](../../Assets/Diagrams/) — see the
README there.

## Important: the deck does NOT embed these files

Inside `Metaprogramming-DotNet10.pptx` the diagrams are **native PowerPoint shapes** —
rounded rectangles and connectors with real arrowheads. You can click any box, retype
it, move it or recolour it. Nothing is a flattened image.

These SVGs exist so the same diagrams can be used in the study guide, in a blog post,
or printed as handouts. Being vector, they stay sharp at any size.
